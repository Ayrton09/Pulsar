# Architecture Decision Records

Formato: contexto → decisión → alternativas → consecuencias. Un ADR aprobado no se edita: se reemplaza por uno nuevo que lo marque como *Reemplazado*.

Estados: `Propuesta` · `Aceptada` · `Reemplazada por NNNN` · `Rechazada`.

Para nuevos ADRs: copiar uno existente y numerar de forma consecutiva.
